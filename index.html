Catatan Penting & Ketentuan

01
Status Proyek Mandiri

ROM ini saya kembangkan secara mandiri di sela waktu luang. Jika prioritas utama Anda adalah kestabilan 100% untuk penggunaan harian tanpa kompromi, saya sangat menyarankan Anda untuk tetap menggunakan HyperOS resmi bawaan pabrik.

02
Pemahaman Risiko Platform MediaTek

Modifikasi sistem pada perangkat MediaTek (Dimensity 8200 Ultra) memerlukan kehati-hatian ekstra. Pastikan Anda sudah memahami segala konsekuensinya dan bersedia bertanggung jawab penuh atas perangkat Anda masing-masing (Do With Your Own Risk - DWYOR).

03
Penyampaian Kendala & Laporan Bug

Jika Anda menemukan kendala atau bug pada ROM ini, mohon untuk tidak sekadar menyampaikan keluhan tanpa data teknis. Sertakan logcat dan penjelasan langkah terjadinya masalah secara objektif agar kendala tersebut dapat saya telusuri.

Cara Pasang ENG Preloader via Fastboot

Unduh berkas preloader_aristotle.bin dari folder Google Drive di bawah, lalu jalankan perintah berikut saat ponsel berada di Mode Fastboot:

bash 
fastboot flash preloader1 preloader_aristotle.bin
fastboot flash preloader2 preloader_aristotle.bin

Catatan: Jika nama berkas yang Anda unduh berbeda, sesuaikan nama berkas pada perintah di atas. Pastikan kedua perintah menghasilkan status OKAY.

Prasyarat Instalasi

✓
Bootloader Terbuka (UBL)

Perangkat Xiaomi 13T sudah dalam status resmi Unlocked Bootloader.

✓
Wajib Firmware HyperOS 2.0 Global

Perangkat harus sudah terpasang firmware OS2.0.214.0.VMFMIXM Global (atau sesama HyperOS 2 Global) sebelum flashing, karena vendor tree yang saya gunakan diekstrak dari versi ini.

✓
Daya Baterai & Alat

Baterai minimal 50%–60%, kabel USB berkualitas, dan PC dengan driver ADB & Fastboot terpasang.

✓
Pencadangan Data Penuh (Backup)

Seluruh data internal akan terhapus total (Format Data wajib dilakukan saat clean flash).

Tata Cara Instalasi (Clean Flash)

1

Masuk ke Mode Fastboot

Matikan perangkat secara menyeluruh. Tekan dan tahan tombol Volume Bawah (-) + Tombol Daya (Power) secara bersamaan hingga muncul tampilan logo Fastboot di layar, lalu hubungkan perangkat ke komputer menggunakan kabel USB.

bash 
fastboot devices
2

Flash Recovery (vendor_boot)

Pasang berkas recovery kernel bawaan ROM (vendor_boot.img) ke partisi vendor_boot perangkat:

bash 
fastboot flash vendor_boot vendor_boot.img

Pastikan eksekusi perintah menghasilkan keterangan OKAY.

3

Masuk ke Mode Recovery

Nyalakan ulang perangkat langsung ke mode recovery yang baru saja dipasang:

bash 
fastboot reboot recovery
4

Format Data (Wajib Clean Flash)

Setelah berada di layar Recovery:
1. Navigasikan menggunakan tombol volume dan gunakan tombol daya untuk memilih menu Factory Reset.
2. Pilih Format data / factory reset, lalu konfirmasi dengan memilih Format data.
3. Tunggu hingga proses penghapusan data internal selesai (Data wipe complete).

5

Pemasangan ROM via ADB Sideload

1. Kembali ke menu utama Recovery.
2. Pilih Apply update lalu pilih Apply from ADB.
3. Di komputer, jalankan perintah berikut:

bash 
adb sideload rom_filename.zip
💡

Catatan Indikator: Di terminal komputer proses umumnya berhenti di sekitar 47% atau Total xfer: 1.00x, dan pada layar ponsel akan muncul pesan Install completed with status 0. Hal ini menandakan proses transfer berkas ROM telah berhasil.

6

Konfirmasi Paket Tambahan & Menyalakan Ulang Perangkat

Perhatikan langkah transisi berikut dengan seksama:
1. Setelah sideload selesai, pada layar Recovery akan muncul dialog konfirmasi:
    "Install additional packages?" (atau pertanyaan pembaruan serupa).
2. Pilih opsi YES.
3. Perangkat akan melakukan restart otomatis dan masuk kembali ke menu Recovery.
4. Setelah berada kembali di menu Recovery, barulah Anda memilih opsi Reboot system now.
5. Tunggu proses booting pertama kali yang memakan waktu sekitar 3 hingga 5 menit hingga masuk ke layar penyiapan awal sistem.

Cara Mengambil Logcat untuk Laporan Bug

Jika Anda menemukan isu teknis, ambil logcat segera setelah kendala terjadi dan lampirkan saat melaporkan:

bash 
adb logcat -d > logcat.txt
